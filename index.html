SmartSoil+

An intelligent soil–water platform built for Tanzanian smallholder and commercial agriculture. Combining agronomic knowledge, rule-based intelligence, and predictive simulation to protect every harvest.

01
Crop-Specific Intelligence
Unique threshold profiles for maize, tomato, and onion. Growth-stage aware stress detection with dynamic Kc integration per crop day.
02
Soil Capital Index
Four proxy indicators replace expensive lab tests. Farmers receive a 0–100 score driven by moisture stability, recovery, saturation, and root-zone consistency.
03
Bilingual Intelligence
Full English–Kiswahili translation. Every alert, diagnostic, recommendation, and WHY explanation translates live. No farmer is excluded by language.
04
Farmer / Expert Mode
Judges and agronomists see full analytics. Farmers see simple colour-coded actions in plain language. One platform, two audiences, zero confusion.
05
Predictive Stress Alerts
Acts BEFORE yield damage occurs. Climate module detects high-ETI + critical-stage combination and generates pre-stress advisories — not reactive alerts.
06
WHY Explanations
No reading is unexplained. "Moisture at 41% FC is below the 50% drought threshold for Tomato during Fruit Set — stomatal closure begins within hours."
⚗ PROTOTYPE SIMULATION MODE — FULL DISCLOSURE
This application uses a rule-based agronomic simulation engine — not live sensor data. All readings are scientifically modelled from FAO/CGIAR crop parameters, Damian's crop profiles, and Saida's soil hydraulics. Diagnostics are experimental estimates. Live ESP32 sensor integration is planned for Phase 2.
TEAM MODULE ATTRIBUTION
Damian — Agriculture Module
Crop water demand, stress thresholds, yield-loss assumptions (MAZ01, TOM01, ONI01), Tanzania-specific rules, Kc coefficients by growth stage
Saida — Soil Hydraulic Module
Soil classification (SOIL01–05), drying rate categories, SCI proxy framework, soil–crop interaction modifiers, waterlogging tolerance
Climate Module
ETI classification, Kc stage integration, predictive stress modelling, climate–soil–crop interaction logic, diurnal cycle simulation
ICT Module
Platform architecture, realistic simulation engine, multi-factor diagnostics, bilingual UI, mobile-first design, sensor ingestion abstraction
